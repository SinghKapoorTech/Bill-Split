# Divit slideshow posts

Ready-to-post slideshows from the creative brief in
`reports/Divit Instagram and TikTok ad plan.md` ("Slideshow types").
Generated by `marketing/slideshows` — edit `posts.json` there and run
`npm run render` to regenerate everything in this folder.

| Folder | Plan type | Slides |
| --- | --- | --- |
| `01-guess-the-split` | Type 3: Guess the split (quiz) | 6 |
| `02-unwritten-rules` | Type 5: Unwritten rules of splitting the bill (listicle) | 7 |
| `03-friend-types` | Type 4: Types of friends when the check comes (relatable) | 7 |
| `04-hot-take-even-split` | Type 10: Hot take (debate) | 5 |

Each post has:

- `9x16/slide-NN.png` — 1080×1920 for TikTok photo mode and Reels. Text stays
  out of the top 250 px, bottom 400 px and right 120 px (platform UI).
- `4x5/slide-NN.png` — 1080×1350 for the Instagram feed carousel.
- `caption.txt` — hook line, download CTA and hashtags.

Before posting (from the plan's checklist):

- Add a TikTok Commercial Music Library sound (business account) or a licensed
  track on Instagram.
- Bill numbers are the plan's example bill and are labelled "EXAMPLE BILL".
- The CTA slide says "Free on iOS & Android" without store badges; add the
  official badges if the post becomes a paid ad.
- Point "link in bio" at the smart download link once it exists.
